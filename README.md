# OX4 in colorectal cancer

The [complete version 0.20.0 package](editions/v0.20.0/OX4_CRC_reproducibility_0.20.0.zip) contains the bulk, spatial pilot, discovery and independent GSE294385 replication modules. [Usage and source details](editions/v0.20.0/README.md). Cite this release via https://doi.org/10.5281/zenodo.24421516.

Creators of this release: Jinglin Wang, Pan Sun, Wei Zhu, Yan Zhang, Yao Tang and Juan Yang. The initial bulk edition by Xia Zhang and Jinglin Wang and the subsequent six-creator spatial edition remain available and are credited in the package. Historical editions and their source materials are preserved. The current release contains research materials and figures.
